## 한 줄 요약

캐릭터·인벤 같은 **진행 데이터**를 슬롯 파일로 저장하고, 프로필에서 이어할 수 있습니다.  
화면·언어 같은 **환경 설정**은 세이브와 따로 둡니다.

---

## 무엇이 되나요

### 저장되는 것 (진행)
- 슬롯마다 파일이 하나씩 있습니다
- 캐릭터 정보(이름, 레벨, 경험치, 체력, 속성 포인트 등). 새 게임은 **레벨 1, 경험치 0**
- 인벤토리·장착·재화·룬·보석
- 등록한 카드 (마을 제단)
- 플레이 시간, 저장 시각 같은 메타 정보

### 원정 중 (`slot_N_run.json`)
- 도전하면 생기고, 방 이동마다 시드·현재 방·방문/클리어·소켓 스냅샷을 씁니다
- 마을로 돌아오면 지웁니다. 등록 카드는 슬롯 파일에 남습니다
- **이어하기는 아직 마을로만** 갑니다. 런 파일이 있어도 던전 한가운데로 돌아가지 않습니다

### 저장되지 않는 것 (지금은)
- 언어·해상도·볼륨 → 설정 파일로 따로 저장 ([설정 일지](2026-08-12-settings.md))

### 슬롯 상태
| 상태 | 의미 |
|------|------|
| 비어 있음 | 새 게임 가능 |
| 정상 | 이어하기 가능 |
| 손상됨 | 불러오기 불가, 삭제는 가능 |
| 호환되지 않음 | 형식이 안 맞아 불러오기 불가, 삭제는 가능 |

### 개발용
- `` ` `` 키로 개발 오버레이를 열면 세이브 폴더 위치를 보고 OS에서 열 수 있습니다

## 직접 확인해 볼 때

1. 새 게임으로 입장 후, 인벤·능력치를 바꾼 뒤 저장이 되는지 확인  
2. 타이틀로 나가 같은 슬롯으로 이어하기  
3. (가능하면) 슬롯 삭제 후 목록이 비는지 확인  

---

## 아직 없는 것

- 자동 저장, 저장 무결성(체크섬 등) 강화  
- 이어하기 시 던전 중간 복귀 (런 파일은 쓰이지만 로드해서 던전을 열지는 않음)

# 일지 — 마을 허브 / 도전 게시판

**날짜:** 2026-08-13  
**관련:** [타이틀·프로필](2026-08-12-title.md) · [던전 맵](2026-08-12-map.md) · [자동 전투](2026-08-13-combat.md)

---

## 한 줄 요약

프로필을 고르면 **마을**로 들어가고, **도전 게시판**에서 확정한 뒤에만 던전 맵이 만들어집니다.

---

## 무엇이 되나요

### 마을
- 새 게임 / 이어하기 → 마을 (고정 방, 맵 생성 없음)
- 지역명 **마을**, 미니맵·맵 탭 없음
- 인벤 / 능력치 / 설정은 그대로 쓸 수 있습니다
- 마을에 들어오면 HP가 가득 찹니다

### 도전 게시판
- 게시판을 클릭하거나 가까이서 Enter로 전체화면 메뉴를 엽니다
- **지역**(묘지 / 숲 / 영지 / 전장)과 **길이**(짧음 / 보통 / 긴)를 고른 뒤 **도전**하면 그때 던전이 생성됩니다
- 언어 설정에 따라 지역·길이 이름이 영어/한글로 바뀝니다
- 열기만 하거나 뒤로 가면 맵은 생기지 않습니다

### 원정 끝
- **보스 승리** 또는 **전멸** → 마을로 돌아옵니다 (진행은 저장)
- **후퇴** → 예전처럼 던전 입구로
- 설정에서 메인 메뉴 → 타이틀

---

## 직접 확인해 볼 때

1. 새 게임 → 마을인지, 미니맵이 없는지  
2. 게시판 → 지역·보통 도전 → 던전 입구, 방 수 대략 12  
3. 짧음/긴으로 방 수 차이, 언어 전환 시 지역명 확인  
4. 전투 패배 → 마을 복귀·HP 회복  
5. 보스 승리(또는 개발 오버레이 강제 승리 후 보스) → 마을  

---

- 후퇴로 원정 포기, 여관·상점

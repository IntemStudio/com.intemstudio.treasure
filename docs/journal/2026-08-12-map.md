# 일지 — 던전 맵

**날짜:** 2026-08-12  
**관련:** [타이틀·프로필](2026-08-12-title.md) · [인게임 HUD](2026-08-12-hud.md)

---

## 한 줄 요약

프로필을 고르면 **마을**로 들어가고, 도전 게시판에서 확정한 뒤 **던전**으로 들어갑니다. 메뉴 **맵** 탭에서 방 배치를 보고 클릭해 **바로 이동(텔레포트)** 할 수 있습니다.

---

## 무엇이 되나요

### 던전 입장
- 타이틀 → 프로필 → **마을** → 도전 게시판 확정 → 던전 씬
- 한 층이 **확정 시** 만들어집니다 (길이: 짧음 8 / 보통 12 / 긴 16)
- **입구**에서 시작하고, 층 어딘가에 **보스 방**이 있습니다
- 같은 조건이어도 방 배치가 달라질 수 있습니다

### 맵 탭
- 방들이 격자처럼 보입니다
- 입구 / 일반 / 보스가 색깔과 대문자(`S` / `N` / `B`)로 구분됩니다
- **가 본 방**과 그 **옆방**만 보입니다. 멀리 있는 미탐험 방은 표시하지 않습니다
- 이동 가능한 방을 클릭하면 그 방으로 즉시 이동합니다
- 이동에 성공하면 맵 메뉴가 닫힙니다
- HUD 지역 이름도 방 종류에 맞춰 바뀝니다

### 이동 규칙
| 상황 | 동작 |
|------|------|
| 이미 가 본 방 | 맵에서 자유롭게 다시 이동 |
| 아직 안 가 본 방 | **지금 방과 맞닿아 있을 때만** 이동 |
| 그 외 | 흐리게 보이고 클릭되지 않음 |

한 번에 **지금 있는 방만** 화면에 올립니다. (맵으로 옮기면 방이 바뀝니다.)

방 **동서남북** 중 옆방이 있는 쪽에 **문**과 키(`W`/`A`/`S`/`D`)가 보입니다. 그 키를 누르면 옆 방으로 이동합니다. (전투 중·메뉴가 열려 있으면 이동하지 않습니다.)

---

## 직접 확인해 볼 때

1. 새 게임 → 마을 → 게시판 도전으로 던전 입장  
2. 문이 있는 방향으로 WASD → 옆 방으로 이동하는지 확인  
3. 메뉴 → 맵 탭  
4. 인접한 방만 열리는지, 방문 후엔 다시 갈 수 있는지 확인  
5. 보스·입구 색과 지역명이 맞는지 확인

## 아직 없는 것

- 던전 진행(층·시드·탐험·방 클리어)을 세이브에 저장  
- 방마다 다른 보상·특수 방 (기본 자동 전투는 [일지](2026-08-13-combat.md))

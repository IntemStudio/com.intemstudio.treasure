**날짜:** 2026-08-17  
**관련:** [인벤 소켓 UI](2026-08-14-socket-ui.md) · [장비](2026-08-16-equipment.md) · [마을](2026-08-15-village.md)

---

## 한 줄 요약

룬·보석 주입은 인벤이 아니라 마을 **대장간** Sheet입니다. 작업대에 올린 뒤 푸터에서 주입합니다. 던전 인벤은 소켓을 보기만 합니다.

---

## 무엇이 되나요

- 허브 `[대장간]` → MenuShell `Tab.SMITHY` (Smithy / 대장간). 던전에선 열리지 않음
- 가운데 작업대: 장비 칸 + 룬/보석 칸. 그 아래 소켓 행. 오른클릭/Enter는 올리기만
- 주입/빼기는 푸터 (`SMITHY_INJECT` / `UNSOCKET`). 즉시 꽂기 없음
- 꽂기/빼기 후 HUD 기술 갱신. 데이터 API는 그대로 (`InventoryData.socket_*`)
- 인벤 `SOCKET` pick 모드 삭제. 상세 소켓 행·`SOCKETED` 뱃지는 남음

---

## 직접 확인해 볼 때

1. 마을 → [대장간] → 주무기 오른클릭으로 작업대에 올림 → 호환 룬 올림 → 주입 → 인벤 상세·(던전) HUD 기술 이름
2. 던전 인벤에서 SOCKET이 없고 꽂히지 않는지
3. 찬 칸 빼기, 비호환·이미 꽂힌 uid가 흐린지. 작업대 칸 오른클릭이 장비에서 빼지 않는지
4. 반지·도구 보석 칸이 보이는지
5. Esc가 대장간만 닫는지

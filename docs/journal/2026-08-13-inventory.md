## 한 줄 요약

가방은 **빈 칸 포함 30칸**이 항상 보이고, `사용 / 최대` 용량 표시로 한도를 확인할 수 있습니다.

---

## 무엇이 되나요

- 가방 격자 칸이 64×64에서 **80×80**으로 조금 커집니다
- 칸 안에는 아이콘이 아니라 **이름 글자**가 가운데 맞춰 들어갑니다 (HUD 퀵슬롯과 같음)
- **빈 슬롯도 전부 표시** (카테고리로 칸을 숨기지 않음). 다른 카테고리 아이템은 흐리게
- 그리드 위에 **`n / 30`** 용량 라벨 (장비 탭)
- **`MOD`(룬·보석)** 탭: `runes[]`+`gems[]`를 한 격자에서 보고 상세·버리기
- 고른 칸은 보라 테두리 대신 스탯 속성 행·설정 행과 같은 **금색 테두리·글자**입니다
- 착용 칸도 가방과 같은 **80×80**이고, 이름 글자를 씁니다
- 가방에서 **맨 오른쪽 칸**을 고른 뒤 오른쪽 키를 누르면 착용 칸으로 넘어갑니다. 착용 칸 맨 왼쪽에서 왼쪽 키를 누르면 가방으로 돌아갑니다

---

## 직접 확인해 볼 때

1. 던전에서 메뉴 → 인벤토리  
2. 가방이 비어 있어도 **30칸**과 `0 / 30`이 보이는지  
3. 칸을 고르면 금색으로 강조되는지  
4. 가방 맨 오른쪽에서 → 로 착용 칸이 선택되는지  
5. 다른 카테고리 탭에서 해당 없는 아이템이 흐리게 보이는지  
6. 룬/보석을 먹은 뒤 **MOD** 탭에서 보이는지

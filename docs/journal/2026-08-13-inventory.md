# 일지 — 인벤토리 슬롯 표시

**날짜:** 2026-08-13  
**관련:** [인벤토리](2026-08-12-inventory.md) · [인게임 HUD](2026-08-12-hud.md)

---

## 한 줄 요약

가방 칸이 조금 커졌고, 아이콘 대신 **아이템 이름**이 보이며, 고른 칸은 스탯·설정과 같은 **금색 테두리**로 강조됩니다.

---

## 무엇이 되나요

- 가방 격자 칸이 64×64에서 **80×80**으로 조금 커집니다
- 칸 안에는 아이콘이 아니라 **이름 글자**가 가운데 맞춰 들어갑니다 (HUD 퀵슬롯과 같음)
- 고른 칸은 보라 테두리 대신 스탯 속성 행·설정 행과 같은 **금색 테두리·글자**입니다
- 착용 칸도 가방과 같은 **80×80**이고, 이름 글자를 씁니다
- 가방에서 **맨 오른쪽 칸**을 고른 뒤 오른쪽 키를 누르면 착용 칸으로 넘어갑니다. 착용 칸 맨 왼쪽에서 왼쪽 키를 누르면 가방으로 돌아갑니다

---

## 직접 확인해 볼 때

1. 던전에서 메뉴 → 인벤토리  
2. 가방 칸에 아이템 이름이 보이는지  
3. 칸을 고르면 금색으로 강조되는지 (스탯 탭 속성 행과 비교)  
4. 가방 맨 오른쪽에서 → 로 착용 칸이 선택되는지, 착용 칸에서 ← 로 가방으로 돌아오는지  
5. 가방 칸과 착용 칸 크기가 같은지

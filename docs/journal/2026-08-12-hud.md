---

## 무엇이 되나요

### 화면 배치
| 위치 | 내용 |
|------|------|
| 왼쪽 위 | 경험치 / 마나 / 체력 바 + 숫자 |
| 오른쪽 위 | 지역 이름 · 앱 버전 · 미니맵 |
| 왼쪽 아래 | 기술 4칸 + 주무기·보조·아이템·음식. 전투 중 기술 칸에 **충전 바** |
| 오른쪽 아래 | 게임 로그 (배속·후퇴 위) |
| 상단 중앙 | 보상 확정 후 획득 이름 (잠깐) |

### 동작
- 메뉴(인벤·맵·능력치·설정)를 열면 HUD는 **숨겨집니다**
- 메뉴를 닫으면 다시 보입니다
- **전투 중에는 HUD·미니맵이 그대로 보입니다** ([일지](2026-08-13-combat.md))
- 던전에서 방을 옮기면 지역 이름이 바뀔 수 있습니다 (입구 / 던전 / 보스 방)

### 지금은 “보기만”
- 퀵 아이템·기술을 **키로 쓰는 입력**은 아직 없습니다
- 전투 중 기술은 **자동**으로 나갑니다 ([장비](2026-08-13-equipment.md))
- 인벤에서 룬을 꽂거나 빼면 HUD 기술 이름이 **바로** 바뀝니다 ([인벤 소켓 UI](2026-08-14-socket-ui.md))

## 직접 확인해 볼 때

1. 던전 입장 후 좌상·우상·좌하 HUD 구성 확인  
2. 메뉴를 열었다 닫아 HUD가 숨김/표시되는지 확인  
3. 맵으로 방 이동 후 지역명 변화 확인

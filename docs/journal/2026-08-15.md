## 플레이 흐름 (갱신)

1. **타이틀** → Start → **프로필(슬롯)**  
2. **마을 허브** (걸어다니지 않음)  
3. 하단 **소문**에서 지역·길이 확정 → **던전**  
4. 방 클리어 → **보상 3택1** → 인벤에서 장착·소켓  
5. 마을 **서가**에서 보유 룬·보석 봉인 → 이웃 칸이 다음 탐험 풀에 열림  
6. 보스 승리·전멸 → **마을** / 후퇴 → 입구  
7. 설정 → 메인 메뉴 또는 종료

## 한 줄 요약

일반·보스 방 **전투에 이기면** 장비가 가방에 들어갑니다. 화면 위쪽에 잠깐 이름이 뜨고, 오른쪽 아래 로그에도 남습니다.

---

## 무엇이 되나요

### 지급
- 방의 적을 **모두** 처치했을 때만 (킬마다 아님)
- 일반 방 1~2개, 보스 방 2~3개
- 무기·방어구만 (물약·광석·낚싯대는 안 나옴)
- 가방이 가득하면 더 받지 않고 “가득” 알림

### 화면
- 상단 중앙에 짧은 획득 문구 (인벤을 자동으로 열지 않음)
- 우하 게임 로그에도 같은 내용

### 원정 중
- 메뉴 → 인벤에서 **갈아끼우기** 가능
- 바꾼 장비는 **다음 방** 전투부터 적용

### 수명
- 전멸·보스 클리어 후에도 가방에 남음 (경험치와 같음)

---

## 직접 확인해 볼 때

1. 일반 방 승리 → 토스트·로그·가방에 무기/방어구  
2. 가방을 가득 채운 뒤 승리 → 기존 칸 유지 + 가득 문구  
3. 후퇴·패배 → 아이템 없음  
4. 클리어한 방 재입장 → 두 번째 드랍 없음  
5. 장착 후 다음 방 → 전투 스탯 반영

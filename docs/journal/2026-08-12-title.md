## 한 줄 요약

게임을 켜면 타이틀이 나오고, 프로필(세이브 슬롯)을 고르면 **던전**으로 들어갑니다.

---

## 무엇이 되나요

### 타이틀 화면
- 게임 이름이 위에 보입니다
- 왼쪽 아래에 **시작 / 설정 / 종료** 메뉴가 있습니다

### 프로필 선택 (슬롯 4개)
- **시작**을 누르면 가로로 슬롯 4칸이 나옵니다
- **빈 슬롯** → “새 게임”으로 시작
- **저장이 있는 슬롯** → 이름, 레벨, 플레이 시간이 보이고 이어하기
- **삭제** → 두 번 확인한 뒤 슬롯을 비웁니다
- 파일이 깨졌거나 버전이 안 맞으면 불러오기는 막고, 삭제는 가능합니다

### 설정·종료
- 타이틀에서도 **설정**을 열 수 있습니다 (인게임과 같은 설정 화면)
- **종료**는 게임을 닫습니다

---

## 직접 확인해 볼 때

1. 게임 실행 → 타이틀 메뉴 확인  
2. Start → 빈 슬롯으로 새 게임 → 던전 입장  
3. 타이틀로 돌아온 뒤, 같은 슬롯에 이름·레벨이 남는지 확인 (세이브가 돌아간다면)  
4. 삭제 확인이 두 단계인지 확인  

---

## 아직 없는 것

- 슬롯에 스크린샷·재화 아이콘 등 실데이터 미리보기  
- 타이틀 BGM, 종료 전 “정말 끌까요?” 확인창

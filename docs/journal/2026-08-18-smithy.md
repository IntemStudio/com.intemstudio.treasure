# 일지 — 대장간 작업대 · 소켓 저장 · 상세 효과

**날짜:** 2026-08-18  
**관련:** [마을 대장간](2026-08-17-smithy.md) · [장비](2026-08-16-equipment.md) · [인벤](2026-08-15-inventory.md)

---

## 한 줄 요약

대장간은 작업대에 **올린 뒤** 푸터에서 주입합니다. 꽂힌 룬·보석은 가방에서 빠지고 그 장비에만 남습니다. 아이템 상세에 적용 효과와 설명이 나옵니다.

---

## 무엇이 되나요

- 가운데 작업대: 장비 칸 + 룬/보석 칸. 오른클릭/Enter는 올리기. 소켓 행은 구멍만 고름
- 룬·보석은 미소켓·미등록이면 고른 구멍과 달라도 올릴 수 있음. 주입은 호환·빈 소켓일 때만 (`SMITHY_INJECT`)
- 찬 소켓이면 푸터 `UNSOCKET`. 아니면 `CLOSE`만. 올리기는 푸터에 없음
- `socket_*_on_item`이 가방에서 제거하고 `ItemData.socketed`에 `rune_id`/`gem_id`를 둠. `unsocket`은 가방으로 반환 (가득이면 실패)
- 옛 세이브는 로드 시 `ensure_socketed_on_items`
- `ItemDetailPanel` `SOCKET_EFFECTS`: 룬 기술(`SKILL_KIND_*_DESC`) · 이 부위 보석(`GEM_FX_*_DESC`) · 접두사(`STAT_DESC_*`)

검증:

```
godot --headless --path . -s res://data/equipment/verify_socket_layout.gd
godot --headless --path . -s res://save/verify_save_v1.gd
```

---

## 직접 확인해 볼 때

1. 마을 → [대장간] → 장비 오른클릭 → 룬 오른클릭 → 주입 → MOD 가방에서 사라지고 장비 상세에 기술+설명이 있는지  
2. 찬 소켓 빼기 → 가방으로 돌아오는지. 작업대 칸 오른클릭이 장비에서 빼지 않는지  
3. 흐린(비호환) 보석도 작업대에 올라가는지. 주입은 보석 구멍을 고른 뒤에만 뜨는지  
4. 던전 인벤에서 꽂히지 않고, 소켓·효과는 보이는지  
5. 언어 전환 후 효과 설명도 바뀌는지

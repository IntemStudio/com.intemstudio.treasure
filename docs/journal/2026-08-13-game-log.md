## 한 줄 요약

화면 **오른쪽 아래**에 전투에서 일어난 일이 텍스트로 쌓입니다. 숫자는 머리 위에 잠깐 뜨고, 로그는 다시 읽을 수 있습니다.

---

## 무엇이 되나요

### 화면
- 우하 반투명 패널. 배속·후퇴 버튼 **위**
- 최신 줄이 아래. 위로 스크롤하면 히스토리
- 메뉴를 열면 HUD와 함께 숨습니다. **전투 중에는 그대로 보입니다**

### 한 줄에 남는 것
- 전투 시작 (적 이름)
- 타격 · 크리 · 스킬 · 회피 · 흡혈 · 반격/보복
- 처치 · 탈진
- 승리 / 패배 / 후퇴

리젠처럼 매초 오르는 숫자는 남기지 않습니다.

### 수명
- 다음 방 전투가 시작돼도 이전 줄은 남고, 구분선이 생깁니다
- 마을이나 타이틀로 나가면 비웁니다
- 세이브 파일에는 들어가지 않습니다

---

## 직접 확인해 볼 때

1. 던전 일반 방 전투 → 우하에 타격/회피 줄, 배속·후퇴가 가려지지 않는지  
2. 회피 시 머리 위 숫자는 없고 로그에 회피가 있는지  
3. 크리·스킬이 평타와 다르게 보이는지  
4. 메뉴를 열면 로그가 숨고, 닫으면 줄이 그대로인지  
5. 다음 방 전투 시작에 구분선이 있고 이전 승리 줄이 남는지  
6. 설정에서 언어를 바꾸면 이미 나온 줄도 바뀌는지  
7. 마을로 돌아온 뒤 로그가 비었는지

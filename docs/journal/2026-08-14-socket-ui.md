## 한 줄 요약

인벤에서 **룬·보석을 장비 소켓에 꽂고 뺄** 수 있습니다. 개발 오버레이 없이 보상 루프가 이어집니다.

---

## 무엇이 되나요

- 장비 상세에 소켓 행(룬 / 핵심 보석 / 보조 보석). 주무기면 공명 상태 한 줄. 이름 옆 **등급**
- **장비 → MOD:** 빈 소켓 확인 → 호환·미등록만 밝게 → 꽂기. 찬 소켓 확인 → 빼기
- **MOD → 장비:** SOCKET → 호환 장비만 밝게 → 빈 칸 하나면 즉시, 여러 개면 소켓 행에서 선택
- MOD 격자에 이미 꽂힌 항목은 `SOCKETED` 뱃지
- 꽂기/빼기 후 HUD 기술만 갱신 (인벤 선택은 유지)
- 버리기는 소켓 참조도 같이 지움
- Esc는 pick 모드만 취소하고, 모드가 없을 때만 인벤을 닫음
- 개발 오버레이 `[아이템]`에서 장비 희귀도를 바꾸면 소켓 수가 다시 잡히고, 세이브에 `rarity`가 남음

---

## 직접 확인해 볼 때

1. 방 클리어로 룬을 받은 뒤 인벤 → 주무기 → 빈 룬 소켓 → 호환 룬 꽂기 → HUD 기술 이름 확인  
2. 보석을 갑옷/보조에 꽂을 수 있고, 룬은 주무기만인지  
3. 비호환 후보가 흐리고 확정이 안 되는지  
4. 빼면 가방에 남고 기술이 되돌아가는지  
5. 같은 룬을 다른 칸에 꽂으면 이전 칸에서 빠지는지  
6. MOD에서 버리기 후 소켓이 비는지  
7. Esc가 pick만 취소하는지  
8. 개발 오버레이에서 희귀도를 올리면 소켓 칸이 늘고, 저장 후 이어하기에도 남는지

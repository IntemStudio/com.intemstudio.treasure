# 일지 — 설정

**날짜:** 2026-08-12  
**관련:** [타이틀·프로필](2026-08-12-title.md)

---

## 한 줄 요약

언어·글꼴·화면·소리를 바꾸고, 인게임에서는 **메인 메뉴로 나가기 / 게임 종료**까지 한 화면에서 처리합니다.  
바꾼 값은 다음 실행에도 유지됩니다.

---

## 무엇이 되나요

설정은 **타이틀**과 **인게임 메뉴(설정 탭)** 둘 다에서 열 수 있습니다.

### 게임 플레이
- **언어:** 영어 / 한국어
- **글꼴:** Sans / Serif

### 조작
- 아직은 “준비 중” 안내만 있습니다 (키 재설정 등은 후속)

### 디스플레이
- 해상도, 창/전체화면/테두리 없음, VSync, 프레임률 제한

### 오디오
- 전체 / 음악 / 효과음 볼륨
- 백그라운드 오디오(창이 뒤로 가도 소리 유지할지)

### 나가기
| 항목 | 동작 |
|------|------|
| 메인 메뉴로 나가기 | 확인 후 타이틀로 (인게임에서만 보임). 메뉴 일시정지를 푼 뒤 타이틀 씬으로 전환 |
| 바탕화면으로 나가기 | 확인 후 게임 종료 |

타이틀의 설정에서는 **나가기 탭 자체가 없습니다.** 종료는 타이틀의 Quit 버튼을 씁니다.

---

## 직접 확인해 볼 때

1. 타이틀 또는 인게임에서 설정 열기  
2. 언어를 바꿔 UI 문구가 바뀌는지 확인  
3. 볼륨·창 모드를 바꿔 바로 적용되는지 확인  
4. 인게임에서 “메인 메뉴로 나가기” 확인 흐름 확인  

---

## 아직 없는 것

- 조작 키 재설정·감도·진동  
- 그래픽 품질/밝기 등 확장 옵션  
- 설정 초기화, 해상도 실패 시 자동 되돌리기

## 한 줄 요약

게임 중 메뉴에서 **가방·장비**를 보고, 장착·정렬·버리기를 할 수 있습니다.

---

## 무엇이 되나요

메뉴를 열면 위쪽 탭에 **인벤토리 / 맵 / 능력치 / 설정**이 있습니다.  
인벤토리 탭은 대략 세 칸으로 나뉩니다.

### 왼쪽 — 가방
- 카테고리: 무기 / 방어구 / 소모품 / 재료 / 도구 / **MOD**(룬·보석)
- 아이템이 격자(칸)에 나열됩니다. 빈 칸도 보입니다

### 가운데 — 상세
- 고른 아이템의 이름·**등급**·설명·옵션·**소켓**을 봅니다
- 장비의 공격/방어 옆 **초록·빨강 숫자**는 같은 칸에 착용 중인 장비보다 높은지/낮은지입니다
- MOD 탭에서는 룬·보석 상세를 봅니다

### 오른쪽 — 장비
- 장착 슬롯, 캐릭터 미리보기, 속성 요약, 무게 느낌 표시
- 장비 칸 폭·간격을 다듬어 글자가 덜 잘리게 했습니다
- 양손 무기를 끼면 한손과 보조가 같이 해제됩니다. 그 상태에서 보조를 끼면 양손이 가방으로 갑니다 ([양손 무기](2026-08-14-two-hand.md))

### 아래 버튼(푸터)
- **정렬** — 시간 → 이름 → 무게 → 희귀도 순으로 순환
- **장착 / 해제** — 가방 우클릭·더블클릭·Enter/A 장착, 착용 칸 우클릭·더블클릭 해제
- **소켓 / 빼기** — 장비 상세 소켓 행에서 룬·보석 꽂기 ([인벤 소켓 UI](2026-08-14-socket-ui.md))
- **버리기** — X
- **닫기** — Esc. 소켓 고르기 중이면 고르기만 취소

---

## 직접 확인해 볼 때

1. 던전에서 메뉴 → 인벤토리  
2. 카테고리를 바꿔 가며 아이템 목록 확인  
3. 아이템을 골라 상세·장착·정렬이 동작하는지 확인. 다른 무기를 고르면 공격 옆 초록/빨강이 착용 무기와 비교되는지 확인  
4. Q/E(또는 패드 어깨 버튼)로 다른 탭과 전환되는지 확인

# 일지 — 인벤토리

**날짜:** 2026-08-12  
**관련:** [능력치](2026-08-12-stats.md) · [인게임 HUD](2026-08-12-hud.md)

---

## 한 줄 요약

게임 중 메뉴에서 **가방·장비**를 보고, 장착·정렬·버리기를 할 수 있습니다.

---

## 무엇이 되나요

메뉴를 열면 위쪽 탭에 **인벤토리 / 맵 / 능력치 / 설정**이 있습니다.  
인벤토리 탭은 대략 세 칸으로 나뉩니다.

### 왼쪽 — 가방
- 카테고리: 무기 / 방어구 / 소모품 / 재료 / 도구
- 아이템이 격자(칸)에 나열됩니다

### 가운데 — 상세
- 고른 아이템의 이름·설명·옵션 등을 봅니다

### 오른쪽 — 장비
- 장착 슬롯, 캐릭터 미리보기, 속성 요약, 무게 느낌 표시
- 장비 칸 폭·간격을 다듬어 글자가 덜 잘리게 했습니다

### 아래 버튼(푸터)
- **정렬** — 시간 → 이름 → 무게 → 희귀도 순으로 순환
- **장착 / 해제**
- **버리기**
- **닫기**

---

## 직접 확인해 볼 때

1. 던전에서 메뉴 → 인벤토리  
2. 카테고리를 바꿔 가며 아이템 목록 확인  
3. 아이템을 골라 상세·장착·정렬이 동작하는지 확인  
4. Q/E(또는 패드 어깨 버튼)로 다른 탭과 전환되는지 확인  

---

## 아직 없는 것

- 월드에서 아이템을 줍거나 전투 보상으로 넣는 흐름  
- 인벤에서 퀵슬롯(아이템·음식)을 직접 편집하는 UI  
- 실제 전투에 따른 내구도·소모 연동 전반

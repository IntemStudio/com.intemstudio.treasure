# 일지 — 개발 오버레이 아이템 탭

**날짜:** 2026-08-17  
**관련:** [자동 전투](2026-08-13-combat.md) · [아이템 카탈로그](2026-08-13-item-catalog.md) · [세이브·로드](2026-08-12-save-load.md)

---

## 한 줄 요약

개발 오버레이 `[아이템]`이 드롭다운 세 줄에서 **부위 하위 탭 + 셀 격자 + 상세 + 획득**으로 바뀌었습니다.

---

## 무엇이 되나요

- 하위 탭: 무기 / 보조 / 투구 / 갑옷 / 다리 / 반지 / 도구 / 보석 / 룬
- 칸은 해당 카탈로그만 (아이콘+이름). 인벤처럼 빈 25칸을 채우지 않음
- 장비 상세는 인벤 `ItemDetailPanel`, 보석·룬은 `ModifierDetailPanel`
- 상세 아래 **획득**. 장비만 희귀도 선택 (`apply_rarity`)
- 지급은 이전과 같음: 장비 가방 / 보석·룬 `try_add_*`

---

## 직접 확인해 볼 때

1. `` ` `` → `[아이템]` → 무기 칸에 아이콘·이름이 보이는지  
2. 칸을 고르면 오른쪽에 상세가 뜨는지, **획득**이 인벤에 넣는지  
3. 보석·룬 탭에서 희귀도가 숨고 상세가 바뀌는지  
4. 장비 희귀도를 바꿔도 소켓 칸 수가 부위 그대로인지  

---

## 아직 없는 것

- 오버레이 격자 키보드·게임패드 이동 (마우스로 칸 선택)

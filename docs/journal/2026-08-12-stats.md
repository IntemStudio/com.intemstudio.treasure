# 일지 — 능력치 (스탯)

**날짜:** 2026-08-12  
**관련:** [인벤토리](2026-08-12-inventory.md) · [인게임 HUD](2026-08-12-hud.md)

---

## 한 줄 요약

메뉴의 **능력치** 탭에서 캐릭터 속성·방어·무게·무기 데미지 표를 보고, 포인트로 속성을 올릴 수 있습니다.

---

## 무엇이 되나요

### 왼쪽
- 초상화
- **속성 포인트**와 속성 목록 (체력 계열부터 장비 하중까지)
- 포인트를 투자할 속성을 고를 수 있습니다

### 오른쪽
- **일반:** 생명, 스태미나, 회복, 포커스 등
- **방어:** 방어력, 포이즈, 열/냉기/전기/역병 등
- **무게:** 최대·현재·등급·게이지
- **무기 표:** 기본 / 속성 보너스 / 기타 / 합계

### 아래 버튼(푸터)
- **레벨업** (포인트 투자 관련)
- **통찰(Insight)** — 추가 정보 보기용
- **뒤로** — 메뉴 닫기

HUD의 체력·마나·경험치는 이 능력치 데이터와 맞춰 표시됩니다.

---

## 직접 확인해 볼 때

1. 메뉴 → 능력치 탭  
2. 속성 목록·오른쪽 수치가 채워져 있는지 확인  
3. 포인트가 있을 때 속성 투자 후 수치가 변하는지 확인  
4. 인벤에서 장비를 바꾼 뒤 무게·관련 표시가 맞는지 확인  

---

## 아직 없는 것

- 전투·피격·소모와 실시간으로 맞물리는 밸런스 튜닝  
- 스탯 화면의 Focus 표기와 HUD 마나 표기를 이름까지 완전 통일하는 정리(후속)  
- 레벨업·성장 연출·사운드

## 한 줄 요약

가방이 **분류 탭마다 5×5(25칸)** 으로 나뉩니다. 세이브는 `inventory.bags`이고, 옛 `slots`는 로드 시 카테고리별로 옮깁니다.

---

## 무엇이 되나요

- 탭: **장비** (무기+방어) / 소모품 / 재료 / 도구 + **MOD**(룬·보석)
- 장비·소모·재료·도구는 각자 `bags[tab]` 25칸
- MOD는 `runes[]`+`gems[]` **합산** 최대 25
- 양손 해제·룻 지급·버리기는 해당 가방 API를 씀
- 슬롯 JSON: `bags` · legacy `slots[]` 호환 로드

---

## 직접 확인해 볼 때

1. 빈 가방에도 탭마다 25칸·용량이 보이는지  
2. 무기와 물약이 서로 다른 탭에만 들어가는지  
3. MOD가 가득 차면 룬/보석 보상이 거절되는지  
4. 옛 세이브(플랫 `slots`)를 열어도 아이템이 사라지지 않는지

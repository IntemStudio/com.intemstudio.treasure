## 한 줄 요약

마을은 **걸어다니지 않는 허브**입니다. 하단에서 **소문·서가·인벤·스탯·설정** Sheet를 열고, 서가는 **룬|보석 5×5**에서 봉인합니다. 예전 제단 단독 UI는 없습니다.

---

## 무엇이 되나요

### 허브
- 프로필 → 마을. GameHud·미니맵·플레이어 이동 없음
- 상단 TopBar(재화·위치·체력), 우측 게임 로그, 하단 HubNav
- 소문 / 서가 / 인벤 / 스탯 / 설정 = 각각 `MenuShell` Sheet (탭 순환 없음)
- Esc는 열린 Sheet만 닫음

### 소문
- 지역 4종 · 길이 3종 → **도전** 확정 시에만 던전 생성
- 예전처럼 월드 게시판을 클릭해 열지 않음

### 서가 (shelf.v3)
- 탭 **룬 | 보석**. 격자 5×5, 칸마다 템플릿 하나
- 시작 시 각 판 `#1`만 OPEN. 봉인하면 그 칸·인접이 OPEN → 다음 탐험 룬/보석 풀
- 보유·미소켓만 봉인. 같은 id 재봉인 불가. 희귀도 단·E1 없음
- 구 세이브 `shelf_common|…` / `discovered_cards`는 로드 시 리셋 후 `#1` 시드

### 개발 오버레이
- 룬/보석 전 칸 해금, 세이브 레이어 도구 등

---

## 직접 확인해 볼 때

1. 새 게임 → 마을인지, HUD·미니맵이 없는지  
2. [소문] → 보통 도전 → 던전 입구, 방 수 대략 12  
3. [서가] → 시작에 각 판 1번만 보이는지  
4. 룬을 받아 봉인 → 이웃이 열리고, 다음 방 룬 보상 풀에 반영되는지  
5. 보스/전멸 → 마을 복귀, 등록 카드가 남는지

## 플레이 흐름 (전체)

1. **타이틀** → Start → **프로필(슬롯)** 선택  
2. 새 게임 / 이어하기 → **마을**  
3. **도전 게시판**에서 길이 확정 → **던전** 생성·입장  
4. 화면 HUD·미니맵으로 자원·지역 확인  
5. 미클리어 방에 들어가면 **방 안 자동 전투**  
6. 승리 시 **보상 3택1** → 인벤에서 갈아끼우기  
7. 보스 승리·전멸 → **마을** / 후퇴 → 입구  
8. 마을 **제단**에서 룬·보석 카드 등록  
9. 메뉴에서 **인벤 / 맵 / 능력치 / 설정** 사용  
10. 설정에서 메인 메뉴로 나가거나 종료

## 공통으로 아직 없는 것 (큰 그림)

- Focus 라벨을 마나와 맞추기 · 무게/원소 전투 보정 — [능력치 전투 매핑](2026-08-13-stats.md)  
- 이어하기 시 던전 중간으로 복귀 (런 파일은 원정 중 쓰이지만, 타이틀에서는 마을로만 감)  
- 조작 키 재설정, 퀵/기술 실사용 입력  

기능별 “아직 없는 것”은 각 일지에 적어 두었습니다.

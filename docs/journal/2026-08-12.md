# 개발 일지 — 2026-08-12

오늘 한 작업으로 **타이틀부터 던전·메뉴 UI까지** 플레이 가능한 기반이 갖춰졌습니다.  
아래는 기능을 나눠 쓴 일지입니다. 비개발자·기획·QA가 “무엇이 되는지”만 보고 싶을 때 읽으면 됩니다.

상세 스펙·파일 경로는 각 일지 하단의 **구조/설계 문서**를 보세요.

## 플레이 흐름 (전체)

1. **타이틀** → Start → **프로필(슬롯)** 선택  
2. 새 게임 / 이어하기 → **던전** 입장  
3. 화면 HUD·미니맵으로 자원·지역 확인  
4. 미클리어 방에 들어가면 **방 안 자동 전투**  
5. 메뉴에서 **인벤 / 맵 / 능력치 / 설정** 사용  
6. 설정에서 메인 메뉴로 나가거나 종료

## 공통으로 아직 없는 것 (큰 그림)

- 전투 고급 스탯(스태미나·크리·드랍 패널) — 기본 자동 전투는 [일지](2026-08-13-combat.md)  
- 던전 진행(층·시드·탐험) 세이브  
- 조작 키 재설정, 퀵/기술 실사용 입력  

기능별 “아직 없는 것”은 각 일지에 적어 두었습니다.

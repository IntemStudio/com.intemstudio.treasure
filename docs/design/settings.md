# 게임 설정 — 설계

메뉴 셸 Settings 탭 / 타이틀 Settings 오버레이에서 쓰는 **환경 설정 UI**.  
**세이브 슬롯 관리**는 프로필 선택([`title.md`](../architecture/title.md))에 두고, 설정 화면에서는 제거한다.

**v1 현황(구조):** [`docs/architecture/settings.md`](../architecture/settings.md)  
이 문서는 스펙·확정 결정·후속 로드맵을 담는다.

---

## 목표

플레이어가 **언어·화면·오디오**를 바꾸고, 인게임에서 **메인 메뉴 / 데스크톱 종료**까지 한 화면에서 처리한다.  
설정은 슬롯 JSON과 분리된 `user://settings.cfg`에만 저장한다([`save-load.md`](../architecture/save-load.md) 레이어 3).

---

## 화면 구성

Settings 본문 상단에 **서브 탭**을 둔다. (MenuShell TopBar의 Settings와 별개.)  
`[1]` / `[3]`(인게임) · `[Q]` / `[E]`(타이틀) 키캡은 탭 목록 좌·우에 붙인다(행 전체로 밀어내지 않음).

```
┌─ [1] 게임 플레이 · 조작 · 디스플레이 · 오디오 · 나가기 [3] ─┐  ← 인게임
│  (타이틀에서는 [Q] … [E])                                   │
│  설정 행 (좌)              │  선택 항목 제목·설명 (우)     │
│                          │                              │
└─ [Esc] 뒤로 ────────────────────────────────────────────┘
```

| 영역 | 내용 |
|------|------|
| 서브 탭 | 게임 플레이 / 조작 / 디스플레이 / 오디오 / 나가기 |
| 본문 | 좌: 컨트롤 행 · 우: 포커스 항목 설명. 나가기는 좌 목록 · 우 제목·설명(+확인) |
| 푸터 | `BACK` (FooterPrompts). 카테고리/전체 초기화는 후속 |

**그래픽** 탭은 두지 않는다. 해상도·모드·VSync·프레임률은 **디스플레이**에 모은다.

---

## 탭 스펙

### 1. 게임 플레이

섹션 **사용자 인터페이스**만.

| 항목 | 컨트롤 | 비고 |
|------|--------|------|
| 언어 | 사이클 (en, ko) | `LocaleManager.set_language` |
| 폰트 | 사이클 (Sans / Serif) | `sans`=Noto Sans KR, `serif`=Noto Serif KR |

### 2. 조작

**플레이스홀더.** 좌 “준비 중”, 우에 후속 안내 설명. 리바인드·감도 미구현.

### 3. 디스플레이

| 항목 | 컨트롤 | 비고 |
|------|--------|------|
| 해상도 | 사이클 | 고정 후보 중 스크린 이하 |
| 디스플레이 모드 | 사이클 | window / fullscreen / borderless |
| VSync | 체크박스 + 켜기/끄기 | |
| 프레임률 | 사이클 | 0(제한 없음), 30, 60, 120, 144 |

### 4. 오디오

| 항목 | 컨트롤 | 비고 |
|------|--------|------|
| 전체 | 슬라이더 0–100% | Master |
| 음악 | 슬라이더 0–100% | Music |
| 음향 | 슬라이더 0–100% | SFX |
| 백그라운드 오디오 | 체크박스 + 켜기/끄기 | 포커스 아웃 시 유지 여부 |

버스: `default_bus_layout.tres`의 Master / Music / SFX.

### 5. 나가기

| 항목 | 동작 |
|------|------|
| 메인 메뉴로 나가기 | 확인 → `UIManager.return_to_title()` (미저장 버림) |
| 바탕화면으로 나가기 | 확인 → `get_tree().quit()` |

확인은 우측 **예/아니요** 한 단계. Cancel은 확인 중이면 취소, 아니면 설정/메뉴 닫기.

| 진입점 | 메인 메뉴로 | 바탕화면으로 |
|--------|-------------|--------------|
| 인게임 MenuShell | O | O |
| 타이틀 Settings | 숨김 | O |

타이틀 좌하단 Quit은 유지(동일 `quit()`).

## 확정 결정

| 항목 | 결정 |
|------|------|
| 탭 | 게임 플레이 / 조작 / 디스플레이 / 오디오 / 나가기 |
| 본문 | 좌 컨트롤 · 우 설명 (`SETTINGS_DESC_*`) |
| 토글 | 체크박스 + On/Off 문구 |
| 서브 탭 입력 | 타이틀 `Q`/`E` (`ui_nav_*`), 인게임 `1`/`3` (`inventory_category_*`). 인게임 Q/E는 TopBar 전용 |
| 폰트 | 게임 플레이 탭 사이클. `sans`=Noto Sans KR, `serif`=Noto Serif KR. `ThemeDB` + UI 테마 `default_font` |
| 첫 실행 디스플레이 | 에디터: 창 1600×900 / 빌드: 전체화면 1920×1080 (`OS.has_feature("editor")`) |
| 뷰포트 | 디자인 기준 1920×1080 유지 (`project.godot` + stretch) |
| 저장소 | `user://settings.cfg`, **SettingsManager** 단일 소유 |
| 슬롯 UI | 설정에서 제거 → 프로필 선택만 |
| 즉시 적용 | 언어·폰트·볼륨·VSync·백그라운드·해상도/모드 변경 즉시 (롤백 카운트다운은 v1.1) |

## 설정 파일

```
[ui]
locale=en
font_family=sans     # sans | serif

[display]
width=1920            # 에디터 첫 실행 기본: 1600
height=1080           # 에디터 첫 실행 기본: 900
mode=fullscreen       # 에디터 첫 실행 기본: window  (# window | fullscreen | borderless)
vsync=true
max_fps=0          # 0 = 제한 없음

[audio]
master=1.0
music=1.0
sfx=1.0
background=false
```

부트: SettingsManager `apply_all`. 언어는 LocaleManager → TranslationServer.  
cfg가 이미 있으면 저장값이 첫 실행 기본보다 우선한다.

## 입력

| 입력 | 동작 |
|------|------|
| 타이틀 `[Q]` / `[E]` | 서브 탭 순환 |
| 인게임 `[1]` / `[3]` | 서브 탭 순환 |
| 상하 | 행(또는 나가기 목록) 포커스 |
| 좌우 / Accept | 사이클·슬라이더·토글 |
| 나가기 Accept | 확인 진입 |
| Esc / B / BACK | 확인 취소 또는 닫기 |

타이틀·인게임 동일 `settings_content` 재사용. 키캡 라벨은 진입점에 맞게 갱신.

## 비목표 (당분간)

- 그래픽 탭, 밝기/대비/채도, HDR, 품질 프리셋

- 카테고리/전체 초기화, 나가기 전 자동 저장, 클라우드 동기화

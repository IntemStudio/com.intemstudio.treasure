# 게임 설정 — 후속 설계

**v1 현황(구조):** [`docs/architecture/settings.md`](../architecture/settings.md)

슬롯 관리는 프로필 선택([`title.md`](../architecture/title.md)). cfg는 세이브 JSON과 분리([`save-load.md`](../architecture/save-load.md) 레이어 3).

| 단계 | 범위 | 상태 |

| **v1.1** | 조작 실내용, 초기화, 해상도 적용 실패 카운트다운 롤백 | 설계만 |

---

## v1.1 — 조작·안전 (예정)

조작 탭은 지금 “준비 중” 플레이스홀더다.

- 키/패드 **리바인드**, 감도, (선택) 진동
- 카테고리 또는 전체 **기본값 초기화**
- 해상도/모드 적용 실패 시 **카운트다운 롤백** (즉시 적용은 유지)

푸터에 초기화 프롬프트를 둘지, 탭 안으로 넣을지는 구현 직전 확정.

---

## v2 — 게임 플레이·그래픽 (예정)

**그래픽** 탭은 계속 두지 않고, 필요할 때만 디스플레이를 확장하거나 탭을 추가한다.

- 게임 플레이: 카메라, 오토 타겟, 자막, 게임 로그 상세도 ([`game-log.md`](game-log.md) v1.1)
- 그래픽: 밝기/대비/채도, HDR, 품질 프리셋
- 오디오: 대화 버스, 출력 장치, 품질

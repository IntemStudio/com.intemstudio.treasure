# 세계관 — 보물 사냥꾼 (단독 모험가)

플레이·카피·후속 설계의 **시점**만 고정한다. 시스템 로드맵이 아니다.  
본체 루프: 룬·보석 · 공명 · 제단 봉인 · 서가 기록 · 인접 해금 — [`equipment.md`](equipment.md) · [`altar.md`](altar.md) · [`bookshelf.md`](bookshelf.md) (`shelf.v3`).  
허브 구조: [`village.md`](village.md). 보상: [`loot.md`](loot.md). 분지 수색(시스템): [`basin.md`](basin.md).

프로젝트명: `treasure-hunter`.

---

## 한 줄

혼자 폐허를 도는 **보물 사냥꾼**이다. 산 채로 가져온 **룬·보석**으로 **자기 비기(공명)** 를 만들고, 마을 **제단**에 바쳐 **이름만 남긴다**. 그 관습이 이 분지를 덮고 있는 잠든 구절을 붙들어 둔다.

---

## 확정 결정

| # | 결정 |
|---|------|
| 1 | 시점 = **단독 모험가**. 길드 소속·계급·평판 트랙은 기본 세계관에 넣지 않는다. |
| 2 | 진짜 보물 = **룬·보석**. 장비는 현장 도구. 골드는 여비·재출발 (본체 진행 아님). |
| 3 | 룬 = 잠든 **구절/비기**. 보석 = 그 비기에 붙는 **성질**. 공명 = 장비+룬+보석이 맞물려 깨어난 기술. |
| 4 | 전투는 빌드를 **읽는 무대**. 원정의 성취감은 “클리어”보다 “이 조합으로 싸웠다 / 무엇을 건졌다 / 무엇을 남겼다”. |
| 5 | 등록 = 룬·보석 개체를 **제단에 바치고 기록으로 남김**. 되돌릴 수 없음. 인접 칸이 드랍 풀에 열린다. 세계관: 한 줄을 세계에 돌려주고 다음 구절이 들린다. |
| 6 | 책장/서가 = **확인된 룬·보석 기록만**. 봉인 UI 없음. 등록이 세계에 정보를 푸는 장치다. 이야기 진행 게이지는 퀘스트 XP가 아니라 **읽은 소문 + 봉인한 이름**. |
| 7 | 마을 = **쉼터**. 직장·영지가 아니다. 게시판 = 소문·현상·누가 남긴 지도 = **세계 지도**. 제단 = 오래된 봉인 관습이자 분지를 덮은 **작은 뚜껑**. 대장간 = 장비에 룬·보석을 맞추는 곳 (공명). |
| 8 | 던전 = 주인이 잊힌 **보물 구멍**. 묘지·숲·영지·전장은 네 나라가 아니라 **같은 입을 덮은 네 상처**. 국가 서사·구원 플롯·액트 캠페인·선택받은 자는 금지. **조사**(이 쉼터는 무엇을 덮고 있는가)는 허용. |
| 9 | 다키스트 던전 햄릿 등은 **허브 UX 참고**일 뿐 세계관 차용이 아니다. |
| 10 | 쉼터에서 부르는 손은 **펠·난·브람·오샤**(여관이 생기면 **던**). 한 마디, 성 없음. HubNav·시트 제목은 **장소**(게시판·제단·서가·대장간). 이름과 대사 한 줄은 시트 본문 맨 위만(제단은 NPC 없음). 창세 신화·왕국사·선행자 고유명·쉼터 지명은 쓰지 않는다. 구절·이름돌·가운데 질문은 무명. 이야기는 **돌·소문·서가 구절**로 적는다. NPC는 구절을 해설하지 않는다. |
| 11 | 카피·설계에서 **「유물」을 쓰지 않는다.** 플레이어가 모으는 것은 **룬**과 **보석**. 둘을 한꺼번에 부를 때는 **룬·보석** (상위 통칭·영문 relic 금지). 탭 라벨 `MOD`는 UI 약칭으로만 유지. |
| 12 | 이름돌 = 이전 사냥꾼이 남긴 **귀환 표식**. 세계관 말로 웨이포인트·마법 포탈이라 하지 않는다. |
| 13 | 마지막 구멍 = **제단 아래**. 다섯 번째 대륙·지역 핀이 아니다. 가운데 질문이 열린 뒤에만 게시판에 점이 생긴다. 로드아웃은 새 열쇠가 아니라 이미 봉인한 이름. |
| 14 | 결말 세 갈래: **가져간다** / **남긴다** / **비운다**. 왕이 돌아오지 않는다. 구현 조건은 [`basin.md`](basin.md). |
| 15 | 구절 네 행의 말투는 고정. 이름돌에서만 한 줄씩. **셋**이면 가운데 질문이 열린다. 넷을 다 모을 필요는 없다. |

## 플레이 루프 (세계관 읽기)

```
마을 (쉼터)
  → 게시판: 소문을 고르고 들어간다
  → 던전: 싸워 장비·룬·보석을 건진다 (본체 진행은 룬·보석)
  → 귀환: 산 자만 가져온다
  → 대장간: 장비에 룬·보석을 맞춘다 (공명)
  → 제단: 남기고 싶은 룬·보석을 바친다
  → 서가: 이름·이웃이 열린 걸 본다
  → 이웃 룬·보석이 열려 다음 수색 풀에 합류한다
```

전멸은 이번 원정의 끝이다. **이미 봉인한 이름**과 메타 가방은 남는다 — “죽은 뒤에도 남긴 것”이 진행이다.

사냥꾼은 보물을 건지러 왔다. 그 동기는 유지한다. 봉인은 수집 UI가 아니라, 이 땅에 남은 **기록으로 잠그는 습관**이다.

## 분지

대륙·왕국·국경을 그리지 않는다. 땅은 **하루면 네 입구에 닿는 변두리 분지** 한 장이다.

가운데 **이름 없는 쉼터**. 사방에 보물 구멍 네 개. 길은 끊겨 있다. 개울·저습·먼 연기는 지형 얼룩일 뿐 선택 지역이 아니다. 걸어다니는 오버월드는 없다.

| 방향 | 상처 | 겉 | 증언 |
|------|------|----|------|
| 북 | 묘지 | 돌과 뼈 | 이름을 묻어 잠들게 했다 |
| 서 | 숲 | 뒤틀린 나무 | 땅이 상처를 덮었다 |
| 동 | 영지 | 피 묻은 장원 | 피로 이름을 붙들려 했다 |
| 남 | 전장 | 잔해와 끊긴 길 | 전쟁이 봉인을 갈랐다 |

구멍은 멀리 있는 나라가 아니라 얼룩 **안에서 깊어진다**. 한 원정은 한 구역의 수색이다.

| 상처 | 입구 | 중간 | 심층 | 수호자 |
|------|------|------|------|--------|
| 묘지 | 외곽 묘역 | 납골당 | 지하 묘실 | 뼈 수호자 |
| 숲 | 뒤틀린 오솔 | 거미 수풀 | 뿌리 둥지 | 둥지 어미 |
| 영지 | 핏빛 정원 | 하인 회랑 | 연회 홀 | 뱀파이어 군주 |
| 전장 | 잔해 들판 | 약탈 진영 | 유령 참호 | 전쟁 망령 |

수호자는 지역 마스코트가 아니라, 잠든 구절의 **한 조각을 붙잡은 것**이다.

이름돌은 입구·중간·심층에 남는다. 수호자 구멍에는 없다. 이름돌은 구역↔쉼터. 같은 층 방 이동(Map 탭)과 겹치지 않는다.

화산·늪·성소 건물은 지도에 핀으로 올리지 않는다. 보석 훅과 제단의 메아리로만 남긴다.

## 하나의 질문

게시판 한가운데, 처음엔 안개다.

> 이 쉼터는 무엇을 덮고 있는가.

구원이 아니라 **조사**다. 선행자는 고유명을 쓰지 않는다. 서가 첫 칸이 이미 열린 이유, 제단에 한 획만 남은 이름, 네 구멍의 같은 필적 — 그 빈칸이 선행자다.

세 겹. 순서 없음. 어느 상처부터든 된다.

1. **겉** — 네 입구. 파묻힌 룬·보석을 찾는다.
2. **교차** — 이름돌이 같은 구절의 다른 행을 보여 준다. **셋**을 읽으면 가운데 안개가 걷힌다.
3. **밑** — 네 구멍은 입구가 네 개인 한 구멍이다. **제단 아래**가 마지막 수색이다.

교차 소문은 새 던전을 만들지 않는다. 이미 있는 다음 구역의 카피·한 방·룻 한 줄만 바꾼다.

---

## 구절 네 행

이름돌에서만 한 줄씩. 창세 전문을 쓰지 않는다. 말투 고정.

1. 묘지 — *이름을 남기면 잠든다*
2. 숲 — *덮이면 잊힌다*
3. 영지 — *피로 붙들면 내 것이 된다*
4. 전장 — *갈리면 깨어난다*

---

## 제단 아래

마지막 구멍이다. 다섯 번째 대륙이 아니다. 가운데 질문이 열린 뒤에만 게시판에 점이 생긴다. 지도의 중심이 쉼터였던 이유다.

로드아웃은 새 열쇠가 아니라 **이미 봉인한 이름**이다. 서가가 이야기 인벤토리이자 마지막 수색의 풀이다.

---

## 결말 세 갈래

왕이 돌아오지 않는다. 분지는 분지다. 마지막 구절을 어떻게 다루는지만 갈린다. 구현 조건은 [`basin.md`](basin.md).

| 갈래 | 행위 | 세계에 남는 것 |
|------|------|----------------|
| **가져간다** | 마지막 구절을 가방에 넣고 쉼터를 떠난다 | 구멍은 그대로다. 사냥꾼답다. |
| **남긴다** | 마지막 구절의 이름을 남긴다 | 입구가 다시 잠긴다. 다음 첫 칸이 된다. |
| **비운다** | 서가의 이름을 더 열어 잠든 것을 깨운다 | 제단 아래가 더 깊다. |

## 용어 (카피·데이터 공통)

| 게임 요소 | 세계관 말 | 피하기 |
|-----------|-----------|--------|
| 플레이어 | 보물 사냥꾼, 혼자 | 길드원, 기사, 선택받은 자, 도로 파수꾼 |
| 룬 (`Rune of ~` / `~의 룬`) | 구절, 비기 | 주문 스크롤(마법학교), `*Verse` 표시명 |
| 보석 | 성질, 파편 | 재화 젬 |
| 룬+보석 | **룬·보석** | 유물, relic, artifact, 카드(세계관 말) |
| 공명 | 깨어남, 맞물림 | 강화 수치 UI 용어만 |
| 등록 | 바치다, 이름을 남기다, 봉인 | 헌납(길드), 분해, 판매 |
| 마을 | 쉼터, 변두리 거점 | 햄릿, 영지, 본부 |
| 게시판 | 소문, 현상, 지도. 손 = **펠** | Embark, 퀘스트 로그, 의뢰 |
| 제단 | 바침, 봉인. NPC 없음 | 도감 앱, 사제, 헌납 |
| 서가 | 확인된 기록. 손 = **난** | 도감 앱, 컬렉션 % |
| 대장간 | 맞추다, 공명. 손 = **브람** | 강화 상점, 인챈트 NPC |
| 상점/여관 | 여비·회복. 손 = **오샤** / **던**(후속) | 길드 상점, 퀘스트 상인 |
| 원정/던전 | 수색, 파묻힌 곳, 보물 구멍 | 성전, 침공 |
| 지역 네 곳 | 상처, 구멍 | 나라, 액트 |
| 귀환 표식 | 이름돌 | 웨이포인트, 포탈 (세계관 말) |
| 골드 | 여비 | 성공의 척도 |
| 장비 | 도구, 장비 | 보물, 유물 |

영문 톤: *delve*, *haul*, *leave a name*, *seal at the altar*.  
길드·회수 의뢰·등재 의무 말투는 쓰지 않는다. *relic* / *artifact*로 룬·보석을 묶지 않는다.

## 본체와의 관계

기능 판정: **이게 없으면 룬·공명·등록 루프가 약해지나?**

| 축 | 역할 |
|----|------|
| 룬 / 보석 / 공명 | 본체 — 현장에서 만드는 비기. 맞춤은 대장간 |
| 제단 봉인 | 메타 행위 — 아쉬운 이별 + 인접 해금. 이야기의 기록 |
| 서가 기록 | 메타 보상 — 열린 룬·보석 드랍. 마지막 수색의 풀 |
| 장비 / 접두사 | 받침 — 소켓 용량·수치 |
| 전투 | 표현 — 공명이 읽히게 |
| 골드 / 상점 | 조연 — 판매/구매가는 경제용. 세계관 주인공 아님 |

장비 룻과 룬/보석 룻이 동급으로 보이면 세계관이 C(로브)로 흐려진다. 공급·카피는 **룬·보석** 쪽으로 기운다.

## 비범위

- 길드 로어, 창세 전문, 왕국사, 선행자 고유명, 쉼터 지명, 쉼터 네 손 외 NPC 이름
- 멀티 히어로·영지 경영·평판 수치
- 「유물」 등 룬·보석 상위 통칭 신설
- 네 상처를 네 나라로 만드는 지명. 화산·늪을 다섯 번째 지역 핀으로
- 시스템 구현 — 분지 수색은 [`basin.md`](basin.md). 제단 봉인은 [`altar.md`](altar.md). 서가 UI·룻 게이트는 [`bookshelf.md`](bookshelf.md). 상점, 특수 방.

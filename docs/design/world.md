# 세계관 — 보물 사냥꾼 (단독 모험가)

플레이·카피·후속 설계의 **시점**만 고정한다. 시스템 로드맵이 아니다.  
본체 루프: 룬·보석 · 공명 · 서가 봉인 · 인접 해금 — [`equipment.md`](equipment.md) · [`bookshelf.md`](bookshelf.md) (`shelf.v3`).  
허브 구조: [`village.md`](village.md). 보상: [`loot.md`](loot.md).

프로젝트명: `treasure-hunter`.

---

## 한 줄

혼자 폐허를 도는 **보물 사냥꾼**이다. 산 채로 가져온 **룬·보석**으로 **자기 비기(공명)** 를 만들고, 마을 서가에 바쳐 **이름만 남긴다**. 이웃 룬·보석이 열린다.

---

## 확정 결정

| # | 결정 |
|---|------|
| 1 | 시점 = **단독 모험가**. 길드 소속·계급·평판 트랙은 기본 세계관에 넣지 않는다. |
| 2 | 진짜 보물 = **룬·보석**. 장비는 현장 도구. 골드는 여비·재출발 (본체 진행 아님). |
| 3 | 룬 = 잠든 **구절/비기**. 보석 = 그 비기에 붙는 **성질**. 공명 = 장비+룬+보석이 맞물려 깨어난 기술. |
| 4 | 전투는 빌드를 **읽는 무대**. 원정의 성취감은 “클리어”보다 “이 조합으로 싸웠다 / 무엇을 건졌다”. |
| 5 | 등록 = 룬·보석 개체를 **서가에 맡기고 기록으로 남김**. 되돌릴 수 없음. 인접 칸이 드랍 풀에 열린다. |
| 6 | 책장/서가 = **확인된 룬·보석 기록** + 봉인 UI. 등록이 세계에 정보를 푸는 장치다. |
| 7 | 마을 = **쉼터**. 직장·영지가 아니다. 게시판 = 소문·현상·누가 남긴 지도. 제단 = 오래된 봉인·등재 관습. |
| 8 | 던전 = 주인이 잊힌 **보물 구멍**. 지역(묘지·숲·영지·전장)은 수색지 분위기일 뿐, 국가 서사·구원 플롯의 무대가 아니다. |
| 9 | 다키스트 던전 햄릿 등은 **허브 UX 참고**일 뿐 세계관 차용이 아니다. |
| 10 | 기본 문서에 NPC 이름·창세 신화·왕국사를 쓰지 않는다. 필요하면 후속. |
| 11 | 카피·설계에서 **「유물」을 쓰지 않는다.** 플레이어가 모으는 것은 **룬**과 **보석**. 둘을 한꺼번에 부를 때는 **룬·보석** (상위 통칭·영문 relic 금지). 탭 라벨 `MOD`는 UI 약칭으로만 유지. |

## 플레이 루프 (세계관 읽기)

```
마을 (쉼터)
  → 게시판: 소문을 고르고 들어간다
  → 던전: 싸워 장비·룬·보석을 건진다 (본체 진행은 룬·보석)
  → 소켓: 현장에서 비기를 조합한다 (공명)
  → 귀환: 산 자만 가져온다
  → 서가: 남기고 싶은 룬·보석을 봉인한다
  → 이웃 룬·보석이 열려 다음 수색 풀에 합류한다
```

전멸은 이번 원정의 끝이다. **이미 봉인한 이름**과 메타 가방은 남는다 — “죽은 뒤에도 남긴 것”이 진행이다.

## 용어 (카피·데이터 공통)

| 게임 요소 | 세계관 말 | 피하기 |
|-----------|-----------|--------|
| 플레이어 | 보물 사냥꾼, 혼자 | 길드원, 기사, 선택받은 자 |
| 룬 (`Rune of ~` / `~의 룬`) | 구절, 비기 | 주문 스크롤(마법학교), `*Verse` 표시명 |
| 보석 | 성질, 파편 | 재화 젬 |
| 룬+보석 | **룬·보석** | 유물, relic, artifact, 카드(세계관 말) |
| 공명 | 깨어남, 맞물림 | 강화 수치 UI 용어만 |
| 등록 | 바치다, 이름을 남기다, 봉인 | 헌납(길드), 분해, 판매 |
| 책장 | 서가, 확인된 기록 | 도감 앱, 컬렉션 % |
| 마을 | 쉼터, 변두리 거점 | 햄릿, 영지, 본부 |
| 게시판 | 소문, 현상, 지도 | Embark, 퀘스트 로그 |
| 원정/던전 | 수색, 파묻힌 곳, 보물 구멍 | 성전, 침공 |
| 골드 | 여비 | 성공의 척도 |
| 장비 | 도구, 장비 | 보물, 유물 |

영문 톤: *delve*, *haul*, *leave a name*, *seal at the altar*.  
길드·회수 의뢰·등재 의무 말투는 쓰지 않는다. *relic* / *artifact*로 룬·보석을 묶지 않는다.

## 공간

| 장소 | 의미 | 비고 |
|------|------|------|
| 타이틀 / 프로필 | 누구의 기록인가 | 슬롯 = 한 사냥꾼의 메타 |
| 마을 | 쉬고, 소문을 보고, 제단에 바치는 곳 | 걸어다니기·영지 경영 없음 |
| 게시판 | 어디로 들어갈지 | 구조는 현행. 카피는 소문/수색 |
| 제단/서가 | 룬·보석을 봉인하고 이름을 남김 | 합친 서가 UI — [`bookshelf.md`](bookshelf.md) |
| 던전 방 | 싸우고 건지는 칸 | 특수 방(룬 제단·보석 광맥)은 map v2 · 세계관과 맞음 |
| 상점/여관 | 여비·회복 | 후속. 넣어도 본체는 아님 |

## 본체와의 관계

기능 판정: **이게 없으면 룬·공명·등록 루프가 약해지나?**

| 축 | 역할 |
|----|------|
| 룬 / 보석 / 공명 | 본체 — 현장에서 만드는 비기 |
| 제단 등록 / 서가 봉인 | 메타 행위 — 아쉬운 이별 + 인접 해금 |
| 책장 | 메타 보상 — 열린 룬·보석 드랍 |
| 장비 / 접두사 | 받침 — 소켓 용량·수치 |
| 전투 | 표현 — 공명이 읽히게 |
| 골드 / 상점 | 조연 — 판매/구매가는 경제용. 세계관 주인공 아님 |

장비 룻과 룬/보석 룻이 동급으로 보이면 세계관이 C(로브)로 흐려진다. 공급·카피는 **룬·보석** 쪽으로 기운다.

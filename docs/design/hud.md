# 인게임 HUD — 설계

메뉴 셸([`menu_shell`](../../ui/shell/menu_shell.tscn))과 분리된 **탐험/전투 중 상시 UI**.  
**v1 현황(구조):** [`docs/architecture/hud.md`](../architecture/hud.md)

참조 레이아웃(초상화·시계·중앙 프롬프트는 채택하지 않음)을 기준으로 영역을 확정했다.

---

## 목표

플레이어가 메뉴를 열지 않고도 **생존 자원(XP/마나/체력)**, **현재 지역·빌드 버전**, **장착·퀵 슬롯·기술**을 한눈에 본다.

---

## 화면 구성

```
┌─ XP / Mana / HP ──────────────── Location · Version ─┐
│                                                      │
│                                                      │
│  [Skills …]                                          │
│  Main · Off · Item · Food                            │
└──────────────────────────────────────────────────────┘
```

| 영역 | 내용 | 비고 |
|------|------|------|
| 좌상 | XP · 마나 · 체력 바(+ `EXP 108/225` 형식, ko: 경험치/마나/체력) | 초상화 없음 |
| 우상 | 지역명 · 버전 | 시계·맵 아이콘 없음 |
| 좌하 | 기술 슬롯(상단) + 장비/소모 4칸(하단) | |
| 중앙 | — | 상호작용·이름표·자막은 HUD 밖 |

메뉴(`MenuShell`)가 열리면 HUD는 **숨긴다**.

---

## 확정 결정

| 항목 | 결정 |
|------|------|
| 마나 | `CharacterStats.mana` / `mana_max` (`mana_max` ← `general.focus`). 스탯 메뉴 Focus 라벨은 후속 |
| 버전 | `AppVersion` 상수 세 숫자. 세이브 포맷 `version`과 분리 |
| 기술 | 4칸, `main_hand.skills` |
| 퀵 아이템/음식 | `InventoryData.quick_item` / `quick_food` + 세이브 |
| 메뉴 | `popup_visibility_changed` → HUD `visible = not is_open` |

---

## 비목표 (당분간)

- 중앙 상호작용 프롬프트, NPC 이름표, 대사 자막
- 미니맵, 퀘스트 트래커, 버프 아이콘 열
- 재화(골드) 상시 표시 — 메뉴 TopBar `CurrencyDisplay` 유지
- 초상화, 시계, 우상 장식 아이콘
- 퀵/기술 키 입력·소모·쿨다운
- 인벤 UI에서 퀵 슬롯 편집
